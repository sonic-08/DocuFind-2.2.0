# DocuFind Explorer

An offline Windows file explorer with automatic drive indexing and fast filename
and path search. See the [project README](docufind/README.md) for usage and
build instructions.

To build an installer, run **Build DocuFind for Windows** from GitHub Actions
and download **DocuFind-Windows-Installer** from the successful run.

The `native-launcher` directory contains the source used to wrap the Windows
app image as the single-file executable delivered alongside this archive.
See its README for the required build inputs.
